# 歌唱训练记录（男声）

目标：**每天 1~2 小时，12 周后成为朋友聚会 / KTV 里能稳住场、还能秀一首的唱歌达人。**

偏好歌手：周杰伦、许嵩、许巍、陈奕迅、汪苏泷、李荣浩、赵雷、宋冬野、毛不易、徐良、周传雄、方大同、陶喆。

## 先明确三件事

1. **假声 ≠ 混声。** 假声是"空、轻、漏气"的高音；混声是"高音区还带着闭合和芯"的声音。KTV 里好听的高音几乎都是混声，假声只用来做点缀和过渡。
2. **你的目标不是唱得更高，而是换声区不破、长句不喘、音准不飘。** 高音是结果，不是练习方法。
3. **别靠感觉判断对错。** 渐强测混声、SOVT 测换声、调音器和录音测音准，见 [自测方法](docs/04-自测方法.md)。
3. **原调不是信仰。** 周杰伦、陶喆、方大同的原调对多数男声偏高，KTV 降 1~2 key 完全正常，唱得好听比唱得原调重要。

## 训练主线

| 阶段 | 周次 | 核心 | 代表曲目 |
|---|---|---|---|
| 地基 | 1–2 | 气息、声带闭合、放松 | 《好久不见》《成都》《十年》 |
| 假声 | 1–4 | 带芯假声、真假声滑音 | 《彩虹》《清明雨上》《叹服》 |
| 弱混 | 5–6 | 平衡混声、换声点 | 《年少有为》《三人游》《借》 |
| 强混 | 7–8 | belt、咽音、哭腔 | 《黄昏》《蓝莲花》《爱很简单》 |
| 高音 | 9–10 | C5 区、转音、爆发 | 《枫》《搁浅》《浮夸》 |
| 整合 | 11–12 | KTV 曲目打磨、表演 | 自选 5 首招牌歌 |
