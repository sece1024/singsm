# 软件与工具：分析并改进自己的声音

工具不是越多越好。先分清你到底要解决哪一类问题，再看清单——**同一个需求只需要留一个工具，装多了只会互相干扰**。

| 需求 | 什么时候用 | 代表工具 |
|---|---|---|
| **A. 唱的时候看反馈** | 练单音、音阶、长音时 | Vocal Pitch Monitor、Singscope、TonalEnergy |
| **B. 唱完再分析** | 每周自测、听不出自己错在哪 | Praat、Audacity、Sonic Visualiser、Logic Flex Pitch / Melodyne |
| **C. 准备练习伴奏** | 降调、放慢、只要伴奏 | Moises、UVR5、Anytune、Audacity |
| **D. 嗓音状态跟踪** | 每周一次，看有没有练伤 | Praat（声学参数）、Voice Tools、分贝仪 |

对应测试方法见 [自测方法](04-自测方法.md)。下面所有工具都只用它的**测量功能**，不用修音功能。

---

## 一、最小可用组合（全免费，够用两年）

| 环节 | 工具 | 成本 |
|---|---|---|
| 实时音高 | **Vocal Pitch Monitor**（Android）/ **Singscope**（iOS） | 免费 |
| 录音 + 频谱 + 降调 | **Audacity** | 免费 |
| 每周嗓音分析 | **Praat** | 免费 |
| 降调 / 分轨伴奏 | **Moises**（免费额度）/ **vocalremover.org** | 免费 |

四件事：**练的时候看音名，录完看曲线，每周量一次嗓音，把伴奏降到自己能唱好的调。**

## 二、A 类：唱的时候能看反馈（实时）

实时反馈的价值是**把"我觉得准"变成"我看到准"**，但要注意：盯着屏幕会分散注意力，建议只在音阶专项时用，唱完整歌曲时关掉。

| 工具 | 平台 | 价格 | 强项 | 注意 |
|---|---|---|---|---|
| **Vocal Pitch Monitor** | Android | 免费 | 实时音名 + 音分偏差 + 历史轨迹，最直白 | 界面朴素，无教程；看的是"你唱到哪个音"，不是"好不好听" |
| **Singscope** | iOS | 免费（内购） | 音高曲线 + 参考旋律叠在一起，跑调一眼看出 | 更适合单音/短句，长句会刷屏 |
| **TonalEnergy Tuner** | iOS / Android | 付费（约 ¥30） | 专业调音器，音分精度高，可做长音稳定性测试 | 功能多，别被各种表盘分散 |
| **Sing Sharp** | iOS / Android | 免费 + 订阅 | 带热身/音域测试/课程，适合不知道练什么的阶段 | 课程是通用模板，别当唯一标准 |
| **Riyaz** | iOS / Android | 免费 + 订阅 | 印度音乐的滑音/音阶训练，练**滑音和转音音准**特别好用 | 曲目风格偏印度，练的是机能不是歌 |
| **Voice Tools** | iOS / Android | 免费 | 测说话音高、音量、音域范围 | 本为跨性别语音训练设计，测"舒适说话音高"刚好用得上 |
| **Vanido** | iOS | 免费 + 订阅 | 实时音高反馈 + 每日练习，游戏化 | 适合养成习惯，深度不足 |

**怎么用（10 分钟）**：开 Vocal Pitch Monitor → 钢琴 App 弹一个音 → 唱长音 5 秒 → 看指针是否稳定停在 ±10 音分 → 音阶 `1-3-5-3-1` 半音上行，看哪个音开始飘。

> 想测自己音域（填 README 的音域档案）：用 **Sing Sharp 的音域测试**或 Voice Tools，从舒适说话音高开始，半音往上/往下唱，记下"不挤"和"不虚"的边界——**不是能挤出多高**。

## 三、B 类：唱完再分析（这是重点）

实时工具只告诉你"这个音准不准"，唱完的分析才能告诉你**"为什么不准、哪一类不准"**。

### 1. Praat（免费，Win/Mac/Linux）——业余能用到的最专业工具

学术语音分析软件，但界面朴素、功能直接。三个必会功能：

| 功能 | 看什么 | 判断 |
|---|---|---|
| **Pitch → 画音高曲线** | 长音的曲线是平的还是抖的/往下掉 | 抖 = 支撑不稳；下坠 = 气息不够 |
| **Spectrogram（频谱图）** | 泛音条纹是否清晰、高频是否有大片"雾气" | 雾气多 = 气声多/漏气；条纹清晰 = 闭合好 |
| **Voice report（声学参数）** | jitter、shimmer、HNR | **只看自己的趋势**，别拿去和医学标准比 |

用法：录音存成 WAV → 拖进 Praat → `View & Edit` 看曲线 → 选中一段 → `Pulses → Voice report`。

> 英文界面不知道从哪下手？看 [Praat 手把手](07-Praat手把手.md)：逐菜单截图式步骤、八个必会单词、判读表和常见错误。

**每周固定测一次**（同一个音、同一个元音、同样音量），三个数字连起来看：

- jitter（频率微扰）：越低越稳，反映声带振动规律性
- shimmer（振幅微扰）：越低越稳，反映音量控制
- HNR（谐噪比）：越高越"干净"，长期下降 = 嗓音疲劳/闭合变差

> 这三个数字的绝对值和别人比没意义（受录音设备影响极大），**只和你上周的自己比**。如果 HNR 连续两周下降、jitter 上升，说明练过头了，减量休息。

### 2. Audacity（免费）——最省事的"录音 + 频谱 + 降调"

- 两轨录：一轨伴奏、一轨人声，能直观看出**你比伴奏快了还是慢了**（波形不对齐）。
- `视图 → 频谱图` 看音色；`效果 → 改变音高` 给伴奏降调。
- 导出 WAV 再丢给 Praat 分析，是标准的家庭录音棚流程。

### 3. Sonic Visualiser（免费）——比 Audacity 更适合看音高

能同时显示**你的音高曲线和伴奏的旋律层**，跑调的位置会直接分开。适合分析"副歌第二句总是低了一点"这种问题。

### 4. Logic Pro（Mac）/ Melodyne —— 看音高曲线最漂亮

- **Logic 的 Flex Pitch**：把音高画成钢琴卷帘，每个音的偏差一目了然，还能看出滑音、颤音、长音衰减。
- **Melodyne**（有 30 天试用）：音高曲线精度最高，能看出"这个字的尾音掉了 30 音分"。
- 这俩本来是修音工具，**练习阶段只用来"看"，禁用自动修音**——修完的音高曲线会让你误以为自己很准。

### 5. 分析时看什么（别只看音准）

| 现象（在曲线/频谱上） | 说明 | 改法 |
|---|---|---|
| 长音曲线平直但整体偏低 20~50 音分 | 气息不足或没开嗓 | 热身加长，降调 |
| 长音尾部往下滑 | 支撑提前撤了 | 练长音 5 秒不掉；句中留呼吸口 |
| 颤音开始得晚、频率不均 | 控制力不够，先别加颤音 | 先练直音稳定，颤音自然出现 |
| 高频"雾气"重、HNR 低 | 漏气/闭合不足 | 回到 `ng` 哼鸣、吸管发声 |
| 换声点附近曲线突然断档 | 换声没连上 | 做 [SOVT 桥接](04-自测方法.md) |
| 波形与伴奏错位 | 抢拍/拖拍 | 跟节拍器练，先念词卡节奏 |

## 四、C 类：准备练习伴奏

练歌的正确调是"**能连唱三遍不挤**"的调，所以降调工具是刚需，不是作弊。

| 工具 | 平台 | 价格 | 用途 |
|---|---|---|---|
| **Moises** | iOS / Android / 网页 | 免费额度 + 订阅 | **首推**：AI 分轨（去人声/留伴奏）+ 变调 + 变速 + 节拍器 + 和弦识别，一站式 |
| **vocalremover.org** | 网页 | 免费 | 快速去人声、变调，临时用足够 |
| **UVR5**（Ultimate Vocal Remover） | Win / Mac | 免费开源 | 本地分轨，质量比免费网页版好，需要一点耐心 |
| **Demucs** | 命令行 | 免费开源 | 同上，适合会写命令的人 |
| **Anytune** | iOS / Mac | 免费 + 内购 | 循环某一小节、变速不变调、EQ 去伴奏里的高频 |
| **Amazing Slow Downer** | iOS / Android / Win / Mac | 付费 | 老牌变速不变调，练难点句 |
| **Transcribe!** | Win / Mac | 付费（约 ¥250） | 变速 + 频谱 + 和弦标注，扒歌用 |
| **YouTube 0.75x / 0.5x** | 网页 | 免费 | 最省事，记得选"保持音高" |

**推荐流程**：Moises 里把伴奏降 2 key、速度 85% → 练到能连唱 3 遍 → 恢复原速 → 再试原调。**先把"对"练出来，再追求"高"。**

## 五、D 类：嗓音状态跟踪（防练伤）

| 工具 | 平台 | 看什么 |
|---|---|---|
| **Praat** | 电脑 | jitter / shimmer / HNR / 最长发声时间（MPT，一口气唱 `a` 能坚持多久） |
| **分贝仪 App**（任意） | 手机 | 做"假声 vs 混声"的音量测试，固定 20 cm 距离对比 |
| **Spectroid** | Android | 实时频谱，看高音时泛音结构还在不在 |
| **Voice Tools** | 手机 | 每天测说话音高：练完高音后说话音变低，就是疲劳信号 |

> **不要**自己买喉镜或做任何"声带检查"——那是耳鼻喉科的事。软件只能测声音，测不了声带。

## 六、别用的东西（重要）

| 别用 | 原因 |
|---|---|
| **K 歌 App 的打分** | 奖励音量、节奏对齐和时长；混响、修音会掩盖音准。同一段唱得挤，分数反而可能更高 |
| **练习时开自动修音**（Auto-Tune / 修音插件 / K 歌 App 的"智能修音"） | 你听到的是修过的声音，永远学不会自己唱准 |
| **大混响练习** | 混响会糊掉音准和漏气，让人误以为唱得不错。练习一律干声 |
| **过度依赖"唱的时候的感觉"** | 骨传导 + 房间反射会骗你，**只信录音** |
| **天天换工具** | 同一个需求固定一个工具（比如音高永远用 Vocal Pitch Monitor），数据才能对比 |

## 七、每周 30 分钟分析流程

| 时间 | 动作 | 工具 |
|---|---|---|
| 0–5 min | 单音校准，3 个音各 5 秒 | Vocal Pitch Monitor + 钢琴 App |
| 5–10 min | 长音稳定性：录一个 `a` 5 秒，看曲线抖不抖 | Audacity → Praat |
| 10–20 min | 本周难点句：降调慢速跟伴奏录 | Moises + 手机录音 |
| 20–25 min | 清唱 8 小节，看音高曲线和伴奏是否分离 | Audacity / Sonic Visualiser |
| 25–30 min | 测 jitter / shimmer / HNR，填 [训练日志](../训练日志/模板.md) | Praat |

**一眼判断有没有进步**：不是"听着顺耳了"，而是——音分偏差变小、长音曲线更平、HNR 没降、同一句录音和上周的波形对齐更准。

## 八、可选硬件（预算有限时按这个顺序买）

1. **一副封闭式耳机**（¥200~400）：录完回放必须用耳机，音箱会二次串音。
2. **USB 电容麦或领夹麦**（¥300~800）：手机内置麦的频响和底噪会让 Praat 数据不准。
3. **Pop filter / 防喷罩**（¥50）：喷麦的爆音会被频谱分析误判成噪音。
4. 隔音棉/衣柜录音：**最便宜的"声学处理"是躲进衣柜唱**，减少房间反射，干声更准。

> 别一上来买声卡和调音台——你这个阶段，手机 + 免费软件能测出的问题，比你练得完的还多。
