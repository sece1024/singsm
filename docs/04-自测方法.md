# 自测方法：怎么判断自己唱得准不准

"准"有两层，必须分开测，否则永远说不清自己错在哪：

| 层 | 问题 | 判断手段 |
|---|---|---|
| **A. 发声状态** | 我唱的是假声 / 混声 / 还是在喊？ | 物理测试（音量、渐强、元音、喉咙感觉） |
| **B. 音高** | 我唱的音和谱子 / 伴奏一样吗？ | 工具测量（调音器、录音软件看音高曲线） |

> 只练 A 不测 B → 音色好但跑调；只测 B 不管 A → 音准了但挤喉咙。**每周两样都要过一遍。**

---

## 一、判断"发声状态"的 6 个物理测试

不用靠"感觉像不像"，全部可验证。**唱同一句歌词，每次只改一个条件。**

### 1. 渐强测试（最能区分假声和混声）

在同一个高音上，从**最轻**平滑加到**最大**，中间不能换气、不能变音高。

| 结果 | 说明 |
|---|---|
| 一加力就变虚 / 漏气 / 破 | 假声（没闭合） |
| 一加力就挤、喉咙紧、音高上飘 | 真声硬顶，不是混声 |
| 能平滑变响，音高稳住，喉咙不紧 | 混声 ✅ |

### 2. 音量测试

手机装分贝仪（或录音软件看波形高度），**麦克风距离固定 20 cm**，同一句分别用真声 / 假声 / 混声唱：

- 假声通常比真声小 **10 dB 以上**，而且"使劲"只会先变成气声和破音，音量上不去。
- 混声能明显变大，且**音高不变、喉咙不痛**。
- 如果音量上去了但喉咙痛 → 那不是混声，是喊。

### 3. 元音测试

高音上唱 `a` / `e` / `o`：

- 混声：元音还能听出是哪个字，字头清楚，能咬字。
- 假声：`a` 容易塌成 `h` 或一团气，字全糊。
- 喊：元音被压扁成 `eh`，但下颌抬起、脖子绷紧、说完一句想清嗓子。

> 高音区允许**窄化元音**（`a → ʌ/eh`），但**不允许糊到听不出字**。

### 4. SOVT 桥接测试（练换声点最有效）

1. 先用 `ng` 哼鸣或**吸管发声 / 唇颤音**，从低音滑到换声点以上再滑回来，要求**全程不断层、不挤**。
2. 保持**完全一样的位置、气压、喉咙状态**，把嘴张开成元音。
3. 对比张嘴后的声音：

| 张嘴后 | 结论 |
|---|---|
| 音色、位置、音量基本不变 | 混声/头声连接住了 ✅ |
| 突然变虚、漏气 | 掉进假声，闭合不够 |
| 突然变挤、变喊、喉咙顶 | 掉回真声，没保住高位置 |

**这一步能过，换声就算通了**——比你反复唱整首副歌有效得多。

### 5. 渐弱测试

从大声一路收到几乎听不见，尾巴不能抖、不能突然断、不能变哑。收不住 = 气息支撑不够；突然断 = 闭合失控。

### 6. 疲劳测试（唯一的安全红线）

副歌连唱 **3 遍**，然后：

| 结果 | 结论 |
|---|---|
| 喉咙不痛、说话音高不变、第二天正常 | 方法基本对 ✅ |
| 喉咙干、想清嗓子、说话变低、第二天沙哑 | 方法错，**立刻停**，回到 SOVT |

> 前 5 项测"对不对"，第 6 项测"能不能继续练"。**6 不过，1~5 全部作废。**

### 附：手摸 + 镜子（30 秒自检）

- 食指轻放喉结：唱高音时喉结**不应明显上跳**（上跳 1 cm 以上就是在挤）。
- 照镜子：下巴不往前伸、脖子不绷、肩膀不抬。
- 唱完摸喉咙两侧肌肉：硬的、酸的 = 用脖子在唱。

## 二、测音高：工具 + 练法

### 工具清单（按门槛从低到高）

> 完整对比、价格、具体用法和避坑见 [软件与工具](06-软件与工具.md)。

| 工具 | 平台 | 用途 |
|---|---|---|
| **Vocal Pitch Monitor** | Android | 实时显示唱到的音名，练单音/音阶最直观 |
| **Singscope / Sing Sharp** | iOS | 实时音高曲线 + 参考旋律 |
| **TonalEnergy Tuner** | iOS/Android | 专业调音器，看音分偏差 |
| **全民K歌 / 唱吧** | 手机 | 只能当娱乐，**分数不能当标准**（见下方警告） |
| **Audacity**（免费） | 电脑 | 录音 + 看波形/频谱，伴奏人声一起录 |
| **Praat**（免费） | 电脑 | 看音高曲线（pitch contour），和专业语音分析同款 |
| **Moises / Vocal Remover** | 手机/网页 | 分离人声伴奏、**降调**、变速 |
| **YouTube 播放速度 0.75x** | 网页 | 慢速跟唱（选"保持音高"） |

> ⚠️ **K 歌 App 的分数别信。** 它主要奖励音量、节奏对齐和"唱够时长"，混响和修音会掩盖音准；同一段唱得挤，分数可能更高。

### 6 个音高练习（每次 10~15 分钟）

1. **单音校准**：钢琴 App 弹一个音 → 跟唱长音 5 秒 → 看调音器偏差。目标：稳定在 **±10 音分**内、5 秒不掉。
2. **音阶跟唱**：`1-3-5-3-1` 用 `ng` 或 `mum`，每遍升半音，直到吃力为止。看换声区附近音准是否开始飘。
3. **跳进准确率**：`1-5-1`、`1-8-1`（八度）来回。**跳进比级进更容易飘**，飘了就是气息没托住。
4. **慢速 + 降调跟伴奏**：伴奏降 2~4 个半音、速度 0.75x 唱，唱准了再恢复原速原调。
5. **清唱录音（照妖镜）**：不带伴奏录 8~16 小节。有伴奏时和声会掩盖跑调，**清唱才是真实水平**。
6. **弹-唱比对**：先弹一个音再唱（对不对？），然后先唱再弹（一样吗？）。第二个方向更难，也更能暴露问题。

### 录音方法（不做好这步，其他都白测）

- 麦克风距离固定（嘴前 20 cm，别贴着），同一个房间、同一个位置录，才能横向对比。
- **关掉所有混响 / 音效 / 自动修音**——它们专门掩盖音准问题。
- 伴奏音量调低一点（约 -6 dB），保证能听见自己的声音。
- 回放**用耳机**；先听整体，再挑 **3 个具体问题**，不要一遍遍全曲听。
- 文件命名 `YYYY-MM-DD-歌名-调.mp3`，每周同一首歌、同一个调，才能 AB 对比。

## 三、对号入座：常见"不准"及原因

| 现象 | 真实原因 | 怎么改 |
|---|---|---|
| 整体偏低半音~一个音 | 没开嗓、气息不足、紧张 | 充分热身，降 1 key 先唱稳 |
| 整体偏高 | 用力过猛、挤 | 降音量、做渐弱测试 |
| 长音句尾往下掉 | 气息支撑不足 | 练长音 5 秒不掉，句子中间留呼吸口 |
| 换声点附近"滑"过去或掉音 | 换声没连接 | 回到 SOVT 桥接测试 |
| 高音上去了但偏低半个音 | 挤着"够"上去，气息和闭合脱节 | 降调，用混声重新找 |
| 转音糊成一团 | 音准和节奏没分开 | 先慢速把每个音唱成单音，再连起来 |
| 自己听着准、录音一听就飘 | 骨传导 + 混响欺骗了你 | 只信录音，不信"唱的时候的感觉" |

## 四、每周自测流程（30 分钟，周日做）

| 时间 | 内容 | 记录 |
|---|---|---|
| 0–5 min | 调音器单音校准（3 个音，各 5 秒） | 偏差多少音分 |
| 5–15 min | 音阶跟唱上行到吃力 | 到哪个音开始飘/破 |
| 15–25 min | 本周难点句 + 伴奏录音 | 哪一句、哪个字不准 |
| 25–30 min | 清唱 8 小节 a cappella | 整体偏高/偏低/个别字 |
| 收尾 | 填 `训练日志/模板.md` 的"自测"栏 | 三项打分 |

**打分（每项 0~2 分，8 分制）**

| 项 | 0 分 | 1 分 | 2 分 |
|---|---|---|---|
| 渐强测试 | 一加力就破/挤 | 能加但喉咙有点紧 | 平滑渐强不痛 |
| SOVT 桥接 | 张嘴就断层 | 偶尔断 | 全程一致 |
| 音准偏差 | 超 ±50 音分 | ±20 音分内 | ±10 音分内 |
| 疲劳测试 | 唱完痛/哑 | 略干但正常 | 无感 |

> 连续两周 ≥6 分再进下一阶段；任何一项 0 分，本周不加新歌。

## 五、一句话总结

- **准不准，不要问感觉，问测试**：能不能渐强、张嘴后声音变没变、调音器上的数字、喉咙第二天痛不痛。
- **音高只信录音**，不信唱的时候的耳朵。
- **发声状态只用 SOVT 桥接 + 渐强 + 疲劳**三项判定，足够。
