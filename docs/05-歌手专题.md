# 歌手专题

[曲单](01-曲单.md) 是按"技术点"组织的；这份是按"人"组织的，回答另一个问题：**我想练某个歌手，该练哪几首、按什么顺序、要避开什么。**

## 怎么用

1. **一个 4 周周期只挑 1 个歌手专题**，从里面选 2~3 首，其余时间照 [每日训练计划](02-每日训练.md) 走。
2. 专题里的"阶段"和 12 周路线对齐（地基 → 假声 → 弱混 → 强混 → 高音 → 稳场），**不要跳级**。
3. **学技术，别学嗓子。** 每个歌手的音色是天生条件 + 长期习惯，硬模仿只会练出坏习惯（下面每节都标了各自的坑）。
4. 判断练没练对，一律走 [自测方法](04-自测方法.md)：渐强 / SOVT 桥接 / 录音音准 / 疲劳。

## 周杰伦

**声线**：男高音偏薄、鼻音重、咬字含糊；高音区大量用"边缘音 / 半假声"，换声点大约 E4–F4。
**练他练什么**：假声与混声的边界控制、旋律感、"高而不虚、弱而不断"。他的慢歌音区其实不夸张，难点全在**控制**。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《彩虹》 | 假声 | 整段轻假声，旋律简单，假声第一课 |
| 《蒲公英的约定》 | 假声 | 轻假声 + 长音收尾 |
| 《菊花台》 | 假声 | 头声为主，弱而不断 |
| 《枫》 | 假声进阶 / 高音 | 副歌卡在假声与混声边界，边缘音训练 |
| 《不能说的秘密》 | 高音 | 副歌 C5 区混声 |
| 《搁浅》 | 高音 | 真假声都得能用的试金石 |
| 《晴天》 | 稳场 | 中音区弹唱，练节奏与咬字 |

**坑**：他的含混咬字是风格，KTV 里照抄最扣分——字要唱出来。高音别伸下巴，《一路向北》最容易挤着唱完。

## 林俊杰

**声线**：男高音，换声区密集（A4–C5 一带常年驻扎），强混靠咽音压缩，现场大量即兴转音。
**练他练什么**：**换声点不破 + 高音压缩 + 耐力**。他的歌几乎整首都泡在换声区，是现成的"换声区教材"；假声用得少，别指望他练假声。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《小酒窝》 | 弱混 | 对唱轻混，松弛不费力 |
| 《背对背拥抱》 | 弱混 | 副歌 A4 平衡混声 + 清晰咬字（教材级） |
| 《她说》 | 弱混 | 弱混 + 边缘音，"轻而不虚" |
| 《那些你很冒险的梦》 | 假声进阶 | 副歌真假声来回切 |
| 《曹操》 | 强混 | belt + 咬字推力 |
| 《修炼爱情》 | 强混 | 副歌 C5 区咽音压缩，**每次不超过 3 遍** |
| 《学不会》 | 高音 | 换声区连续高音，练"一整段不破" |
| 《不为谁而作的歌》 | 高音 | 密集高音 + 快速转音，**日常少碰** |
| 《江南》《一千年以后》 | 稳场 | 中高区稳定输出 |

**坑**：原调对多数男声偏高，**先降 1~2 key**。别用脖子挤那个"亮"——他的亮来自压缩和气息，不是喉咙；挤出来的亮第二天必哑。他的即兴转音别硬抄，先把原旋律唱准。

## 许嵩

**声线**：音色清、轻、气声多，音区不算高，但副歌大量假声 / 轻混；中国风咬字讲究。
**练他练什么**：假声入门、轻机能、气声与"芯"的分辨——他的歌是"漏气假声 vs 带芯假声"最好的辨别材料。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《清明雨上》 | 假声 | 副歌假声换声，中国风咬字 |
| 《有何不可》 | 假声 | 轻混/假声边界，律动与松弛 |
| 《断桥残雪》 | 假声 | 中高区假声，句子长 |
| 《山水之间》 | 假声 | 副歌假声跳进，"落花雨"那句是重点 |
| 《叹服》 | 假声 | 连续假声高音，练耐力与闭合 |
| 《幻听》 | 高音 | 副歌高音 + 情绪 |
| 《素颜》 | 稳场 | 男女对唱，社交神器 |

**坑**：他的"虚"是风格。练的时候必须能听见"芯"，否则越练越散——用 [SOVT 桥接测试](04-自测方法.md) 确认张嘴后没变虚。

## 许巍

**声线**：中低音厚实、喉位低、咬字带颗粒感，belt 直给不花哨，句式规整、呼吸口清楚。
**练他练什么**：胸声支撑、belt 入门、长句气息。**belt 第一课就该是《蓝莲花》**。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《蓝莲花》 | 强混 | "没有什么能够阻挡"标准 belt 入门 |
| 《曾经的你》 | 强混 | 长句 belt + 气息，练"唱着不累" |
| 《执着》 | 强混 | 中高区持续推力 |
| 《故乡》《旅行》 | 稳场 | 中音区，稳 |

**坑**：他的沙哑是音色，别刻意压嗓子模仿，压出来的沙是伤。belt 靠气息推，不靠挤——《曾经的你》最容易唱到后半段没气。

## 陈奕迅

**声线**：男中音，音域不宽但控制力顶级：弱混、气声、边缘音随手切换，粤语咬字极讲究。
**练他练什么**：弱混、气息叙事、弱声控制。他的歌"听着不难，唱起来全不对"——最能暴露控制问题。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《富士山下》 | 弱混 | 副歌连贯混声，粤语咬字 |
| 《葡萄成熟时》 | 弱混 | 长句混声，气息分配 |
| 《陀飞轮》 | 弱混 | 中高区持续混声，耐力 |
| 《K歌之王》 | 强混 | 中高区连续输出 + 叙事 |
| 《十年》《好久不见》《爱情转移》 | 稳场 | 气声、低音、叙事 |
| 《浮夸》 | 高音 | **日常别练**，演出前一个月再碰 |

**坑**：别用大音量唱他，一放就散——他的"轻"是有闭合的轻。粤语歌先逐字抠，别含糊带过。

---

## 汪苏泷

**声线**：少年音、轻机能、音区偏高、节奏轻快，Hook 常用轻假声。
**练他练什么**：快速换声、轻快律动、松弛感。适合在假声阶段当"趣味练习"，不枯燥。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《不分手的恋爱》 | 假声 | 轻快假声 Hook，练快速换声 |
| 《万有引力》 | 弱混 | 轻混 + 律动 |
| 《苦笑》《放不下》 | 假声 | 副歌假声 |
| 《有点甜》 | 稳场 | 对唱，气氛担当 |

**坑**：别把轻机能唱成喊。快歌先念歌词卡节奏，再唱。

## 李荣浩

**声线**：男中音，说话式咬字，鼻腔 / 咽腔共鸣，压缩感强混（《麻雀》）。
**练他练什么**：**混声入门首选**、咬字、律动。音区温和，不容易受伤，进步看得见。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《年少有为》 | 弱混 | 副歌 A4 左右平衡混声 + 清楚咬字（首推） |
| 《模特》 | 弱混 | 鼻腔/咽腔共鸣，轻机能高音 |
| 《戒烟》 | 弱混 | 中高区弱混，句子密集 |
| 《麻雀》 | 强混 | 压缩感强混，练"紧而不僵" |
| 《李白》《老街》 | 稳场 | 说话式律动、中低音咬字 |

**坑**：他听着很"随意"，其实节奏极准，跟伴奏别抢拍。别用鼻音代替气息支撑。

## 赵雷

**声线**：中低音、音色朴素、气息稳定，民谣直白，叙事感强。
**练他练什么**：气息、低音不虚、长句、松弛。地基阶段的"不紧张"全靠他。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《成都》 | 地基 / 稳场 | 气息与叙事，全场大合唱 |
| 《南方姑娘》 | 稳场 | 中低音，松弛 |
| 《理想》 | 强混 | 民谣里的 belt，"理想今年你几岁" |
| 《画》《鼓楼》 | 稳场 | 中音区叙事 |

**坑**：民谣最容易唱成"白嗓念经"，要保持支撑；低音别往下压喉，用气泡音找位置。

---

## 宋冬野

**声线**：低音厚、气声重、音区低，口语化叙事。
**练他练什么**：低声区闭合、气声控制、情绪。低音唱不实的人，练他最有效（也最容易暴露问题）。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《董小姐》 | 稳场 | 气声 + 低音 |
| 《斑马斑马》 | 稳场 | 弱声控制 |
| 《安和桥》 | 稳场 | 长音与情绪 |
| 《莉莉安》 | 稳场 | 中音区 |

**坑**：低音最容易虚——用 `ng` 哼鸣或气泡音找闭合，别靠"压喉咙"做厚度。

---

## 毛不易

**声线**：男中低音、弱混、叙事口吻、长句气息见长。
**练他练什么**：弱混、**小声也有支撑**。他证明了"不用大声也能唱进人心里"。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《借》 | 弱混 | 弱混 + 长句气息 |
| 《东北民谣》 | 弱混 | 叙事转爆发 |
| 《消愁》 | 稳场 | 长句气息，聚会必点 |
| 《像我这样的人》《平凡的一天》 | 稳场 | 中音区叙事、低音弱声 |

**坑**：他的"小"是有闭合的小声，不是漏气。唱《东北民谣》后半段放大音量前，先过渐强测试。

---

## 徐良

**声线**：网络流行时代的少年音，假声多、音色偏薄、句子短。
**练他练什么**：假声、真假声切换。音区高但句子短，适合假声阶段的"高频短跑"。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《红装》 | 假声 | 副歌假声，情绪推力 |
| 《后会无期》 | 假声 | 对唱高音 Hook，假声稳定性 |
| 《坏女孩》 | 假声 | 中高区真假声切换 |
| 《客官不可以》《犯贱》 | 稳场 | 轻快，气氛 |

**坑**：他的"薄"是时代音色，别照着练薄——假声必须带芯，否则 KTV 里只剩气声。

---

## 周传雄

**声线**：哭腔、鼻咽腔共鸣、中高区强混，情绪浓度高。
**练他练什么**：哭腔 / 咽音、强混、情绪与技术的结合。**先练准音高，再加哭腔。**

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《黄昏》 | 强混 | 哭腔 + 强混，副歌长句是精华 |
| 《关不上的窗》 | 强混 | 强混 + 情绪递进 |
| 《青花》 | 假声 | 假声句 + 哭腔混声 |
| 《寂寞沙洲冷》《记事本》 | 稳场 | 中高区叙事 |

**坑**：哭腔是点缀，整段用会挤喉。加哭腔后必做疲劳测试，喉咙紧就是过头了。

---

## 方大同

**声线**：R&B 唱法，假声 + 转音 + 律动，中高区轻机能，黑人音乐底子。
**练他练什么**：假声转音、律动、节奏——**"假声也要有节奏"**，这是他和别人的最大区别。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《三人游》 | 假声 | 假声 + R&B 转音 |
| 《Love Song》 | 假声 | 假声句与真声句交替 |
| 《特别的人》 | 弱混 | 平衡混声 + 长音 |
| 《爱爱爱》 | 弱混 | 轻混律动 |
| 《Singalongsong》 | 高音 | 大量假声与转音，R&B 机能训练 |

**坑**：转音先拆成单音慢练（0.75x），别用"抖"冒充转音。律动错了，音再准也不好听。

---

## 陶喆

**声线**：R&B 教父级，真声 / 混声 / 假声三种档位全用，高音到 C5，即兴转音多。
**练他练什么**：**一首歌三种档位切换**、即兴、律动。练完他的歌，换声区基本就通了。

| 歌 | 阶段 | 训练点 |
|---|---|---|
| 《流沙》 | 假声进阶 | 主歌真声、副歌混声、桥段假声 |
| 《普通朋友》 | 弱混 | 混声 + 转音 + 律动 |
| 《就是爱你》 | 弱混 | 副歌混声，情绪推进 |
| 《爱很简单》 | 强混 | "I love you" 的 belt，混声试金石 |
| 《飞机场的 10:30》 | 高音 | 假声转音 + 高音即兴 |
| 《Susan说》 | 高音 | 戏腔 + 假声，风格化 |
| 《黑色柳丁》 | 高音 | 摇滚 belt，**消耗大** |
| 《小镇姑娘》 | 稳场 | 轻快，律动 |

**坑**：即兴转音别乱加，先把原旋律唱准再谈装饰。高音歌之间至少隔一天，别连着练。

## 一页总结

- **练假声**：周杰伦《彩虹》、许嵩《清明雨上》、徐良《红装》
- **练混声入门**：李荣浩《年少有为》、林俊杰《背对背拥抱》、毛不易《借》
- **练换声区**：林俊杰《学不会》、陶喆《流沙》、周杰伦《枫》
- **练 belt**：许巍《蓝莲花》、周传雄《黄昏》、陶喆《爱很简单》
- **练控制 / 叙事**：陈奕迅《十年》、赵雷《成都》、宋冬野《董小姐》
- **练律动 / 转音**：方大同《三人游》、陶喆《普通朋友》、汪苏泷《不分手的恋爱》
