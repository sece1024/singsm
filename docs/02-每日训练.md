# 每日训练计划（1~2 小时）

## 原则

- **每周练 5~6 天，留 1~2 天休息或只轻唱。** 声带是肌肉，恢复比练习重要。
- **每天必做：热身 10 分钟 + 冷身 5 分钟。** 跳过热身直接唱高音是最容易受伤的做法。
- **痛了就停。** 喉咙刺痛、沙哑超过一天、说话音变低 → 停 2~3 天，只做气泡音和轻声哼鸣。
- **宁少勿猛。** 高音每天练 10~15 分钟足够，练多了只会形成"挤"的习惯。

---

## 1 小时版（工作日）

| 时间 | 内容 |
|---|---|
| 0–10 min | **热身**：气泡音 1 min → 唇颤音五度上下行 → `ng` 哼鸣音阶 → 轻声滑音（siren） |
| 10–25 min | **音阶专项**：当天主题（假声 / 弱混 / 强混 / 转音），半音阶逐步上移，到"有点吃力"就停，不要顶 |
| 25–50 min | **歌曲**：1 首基础歌（稳场曲）+ 1 首技巧歌，只抠难点句，不整首反复唱 |
| 50–55 min | **整首过 1 遍**，录音 |
| 55–60 min | **冷身**：轻声哼鸣下行 + 气泡音 + 喝水 |

## 2 小时版（周末 / 休息日）

| 时间 | 内容 |
|---|---|
| 0–15 min | 热身（同上，更充分） |
| 15–40 min | 音阶专项 + 换声点练习（八度滑音、五度跳进、元音转换） |
| 40–70 min | 技巧歌 A：拆句精练（主歌 / 预副歌 / 副歌 / 桥段分开） |
| 70–95 min | 技巧歌 B 或新歌学习（先哼旋律，再带词） |
| 95–110 min | 两首连唱，模拟 KTV（不暂停、不看词） |
| 110–120 min | 回听录音、记录问题、冷身 |

> 2 小时版中间至少休息 2 次，每次 3~5 分钟，喝水（温水）。

---

## 热身 / 音阶菜单（每天选 3~4 个）

1. **气泡音**：放松喉头，最低音区"啊——"带颗粒感，1 分钟。
2. **唇颤音（lip trill）**：1-2-3-2-1，每次升半音，练气息均匀。
3. **`ng` 哼鸣**：1-3-5-3-1，找到面罩/鼻腔的高位置。
4. **`ng` → `a` / `o` 转换**：保持高位置张嘴，练"高位置 + 打开"。
5. **八度滑音（siren）**：低音滑到假声再滑回，练真假声连接，**不要断层**。
6. **五度跳进 `mum`**：1-5-1，练混声的闭合与支撑。
7. **元音窄化**：高音时 `a → eh/æ`、`o → u`，嘴巴别越唱越大。
8. **半音阶下行**：练音准和声带边缘控制。

## 四个技术点的判断标准

| 技术 | 做对了的感觉 | 常见错误 |
|---|---|---|
| 带芯假声 | 细、集中、不费力，像"有线的气球" | 漏气、发虚、声音散 |
| 弱混 | 小声但能传出去，喉咙不挤 | 用真声硬顶，越唱越哑 |
| 强混 / belt | 有胸声厚度 + 金属芯，像"受控的喊" | 抬下巴、挤喉咙、唱完痛 |
| 换声 | 高低音是同一根线，能滑上滑下 | 到某个音突然"断"或"翻" |
