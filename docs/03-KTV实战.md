# KTV 实战指南

练习的最终目的不是"能唱上去"，而是**在朋友面前稳定、好听、有记忆点**。

---

## 一、先定 5 首"招牌歌"

不要什么都会一点。准备 5 首**闭着眼都能唱、不破音、有情绪**的歌，分工如下：

| 位置 | 作用 | 推荐 |
|---|---|---|
| 开场稳场 | 一开口就好听，不冒险 | 《十年》《成都》《李白》 |
| 气氛合唱 | 全场会唱，拉互动 | 《蓝莲花》《消愁》《素颜》（对唱） |
| 中段招牌 | 展示音色和叙事 | 《富士山下》《年少有为》《董小姐》 |
| 高音炫技 | 全场"哇"的一首，只留一首 | 《枫》《黄昏》《爱很简单》 |
| 收尾 | 情绪收束，不硬顶 | 《好久不见》《平凡的一天》《安和桥》 |

**炫技歌最多一首。** 唱两首高音，第二首一定翻车。

## 二、降调是专业行为

- 周杰伦、陶喆、方大同、陈奕迅（粤语）的原调对多数男声偏高，**降 1~2 key 很正常**。
- 提前在 KTV 点歌机或伴奏 App 里试好降调版本，别到现场才试。
- 判断标准：副歌最高音你能**连唱三遍不挤**，就是对的调。
- 宁可降调唱得好听，也不要原调唱到破音。

## 三、点歌顺序

```
1 首低难度稳场（中低音、慢歌）
→ 1 首气氛合唱
→ 1 首中高难度招牌
→ 别人唱，你休息
→ 1 首高音炫技（状态最好时）
→ 1 首收尾慢歌
```

- 不要一上来就唱最高音的歌，声带没开。
- 两首高音之间至少隔 3~4 首别人的歌。
- 喝酒、冰饮、抽烟后不要唱高音。

## 四、麦克风

- 距离嘴 **3~5 cm**，不要贴着嘴。
- 唱高音时**稍微拉远**，唱低音/气声时**靠近**。
- 不要对着麦克风喷气（"p/b"音），会爆音。
- 混响别开太大，会掩盖音准问题，也让声音糊。

## 五、演唱细节（比高音更加分）

1. **音准第一。** 高音破一点没人记得，跑调全场都听得出来。
2. **咬字清楚。** 周杰伦的歌也要把字唱出来，尤其慢歌。
3. **句尾收住。** 不要每个字都拖长、每个尾音都颤。
4. **有强弱。** 主歌轻、副歌放，别从头到尾一个音量。
5. **看人。** 唱到副歌抬头看朋友，比盯着屏幕加分。
6. **不会唱的歌别点。** 点歌前先确认自己练过。

## 六、常见坑

| 坑 | 后果 | 解法 |
|---|---|---|
| 用假声硬顶整段副歌 | 虚、没气、听着累 | 换成弱混，或降调 |
| 高音抬下巴、伸脖子 | 挤喉咙、破音 | 下巴微收，感觉声音往上往后 |
| 每首歌都唱 | 半小时就哑 | 主动当"点歌/聊天担当"，歇嗓 |
| 只练高音不练音准 | 炫技歌好听，慢歌露怯 | 每天留 10 分钟纯音准练习 |
| 现场试没练过的歌 | 翻车 | 只在练过的 5 首里选 |
| 空腹/饱腹/喝酒后唱 | 气息不稳、反酸 | 提前 1 小时吃点东西 |

## 七、演出前一天

- 不熬夜，不喝酒，不吃辣。
- 只做轻热身，不硬练高音。
- 把 5 首招牌歌各过一遍，确认调。
- 准备好温水，现场小口喝。
