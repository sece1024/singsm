# 曲单：假声与混声（男声）

> 难度：★ 入门 / ★★ 有基础 / ★★★ 需要混声 / ★★★★ 高音区 / ★★★★★ 炫技，日常别硬练
> 音高只写"大致区域"，不同版本/现场会变；练习一律以**你能不挤不破**的调为准。

---

## 一、假声入门（第 1–4 周）

目标：把"漏气假声"练成"有芯假声"，并能和真声滑音连接。

| 歌曲 | 歌手 | 训练点 | 难度 |
|---|---|---|---|
| 《彩虹》 | 周杰伦 | 副歌整段轻假声，旋律简单、气息要求低，最好的假声第一课 | ★ |
| 《蒲公英的约定》 | 周杰伦 | 轻假声 + 长音收尾，练"高而不虚" | ★ |
| 《清明雨上》 | 许嵩 | 副歌假声换声，中国风咬字 | ★★ |
| 《不分手的恋爱》 | 汪苏泷 | 轻快假声 Hook，练快速换声 | ★★ |
| 《有何不可》 | 许嵩 | 轻混/假声边界，练律动和松弛 | ★★ |
| 《断桥残雪》 | 许嵩 | 中高区假声，句子长 | ★★ |
| 《山水之间》 | 许嵩 | 副歌假声跳进，"落花雨"那句是重点 | ★★★ |
| 《叹服》 | 许嵩 | 连续假声高音，练耐力和闭合 | ★★★ |

**练法**：先用 `ng`（哼鸣）找到高位置 → 滑到假声 → 保持"芯"再张嘴成 `u/o` → 最后代入歌词。**不要一上来就唱词。**

## 八、怎么用这份曲单

1. **每个阶段只精练 2~3 首**，不要贪多。一首歌练到"能录下来不发怵"再换。
2. **一首歌拆成三层练**：先哼鸣走旋律 → 再用元音唱 → 最后带词。
3. **高音句单独抽出来练**，不要每次从头唱到尾。
4. **每周固定录一次**同一首歌，存到 `训练日志/` 里对比。
5. 原调唱不上去就**降 1~2 key**，KTV 点歌机基本都支持。
